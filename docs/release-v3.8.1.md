# v3.8.1 — 上傳的自訂海報也自動帶 QR ＋ 已截止／額滿的掃碼引導

發佈日期：2026-09-27
線上版本：<https://competition-manager-hazel.vercel.app>

使用者確認 v3.8.0 的成果（「電腦日期正常了，QR code 正常」）之後指定的方向。

## 一、上傳的自訂海報也會帶 QR

v3.8.0 只有**自動生成**的海報有 QR；如果發佈者上傳了自己的設計稿，分享視窗就只顯示那張圖、沒有 QR。

v3.8.1 把上傳的海報**畫進 canvas 並疊上報名 QR**（右下角白色圓角底卡 ＋ 狀態說明）：

- **預覽＝複製＝下載**：三者都吃同一張 canvas，所以「下載海報」拿到的就是印出來帶 QR 的那一張。
  （順帶修掉一個舊毛病：以前自訂海報的「下載」其實會拿到自動生成的那張，不是自己上傳的圖。）
- 上傳圖的底色無法預期 → 說明文字加了一層深色底，保證看得見。
- 畫布尺寸跟著上傳圖（上限 1000px 寬），QR 大小按比例（寬度的 16%，最少 120px），邊距 4%。
- **讀不到圖時會退回顯示原圖並說明「沒有 QR」**，不會讓視窗空著或壞掉。

## 二、掃到「已截止／額滿」要引導，不要讓人白掃

海報印出去就改不了，所以 QR 旁的說明要跟著賽事狀態走。新增純函式 `shareStateGuide(item)`：

| 賽事情況 | 掃碼說明 |
|---|---|
| 開放報名中 | 📷 用手機掃碼直接報名 |
| **已額滿＋有候補** | 📷 已額滿，掃碼登記候補 |
| 報名已截止（**但沒額滿**） | 🔒 報名已截止（掃碼看資訊） |
| 報名尚未開放 | 🕒 報名尚未開放（掃碼看賽事） |
| 已取消 | ⛔ 此賽事已取消 |
| 進行中／已結束／日期未定 | 🏁／📷 掃碼看賽事資訊 |

**★最容易搞錯的一點**：`waitlist_enabled` 只代表「這場有候補機制」，不代表額滿。
所以「額滿」與「已截止」是分開判定的（後端狀態原因優先，其次才用名額與報名人數推算）——
名額還有剩、只是報名期過了，說成「已額滿可候補」會誤導。這條有專門的測試。

同時，**報名視窗**在「真的額滿且有候補」時會多一行：
「🕒 目前名額已滿，送出後會排入候補（有人取消就依序遞補）」——掃碼進來的人才知道按了會怎樣。

群組文案（`buildShareText`）也跟著狀態走：非開放報名時多一行「🔔 目前狀態：…」，連結那段的說明改成「賽事頁面」。
