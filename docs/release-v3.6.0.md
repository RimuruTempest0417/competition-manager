# v3.6.0 — 使用說明（依身分給對應內容）＋ 管理員操作清單

發佈日：2026-09-27

## 為什麼先做這一版

直接查資料庫看到的事實：賽事有 9 筆（含軟刪除）、帳號 5 個、稽核紀錄 208 筆，
但**有效報名是 0 筆**（`registrations` 有 3 筆，全部是已軟刪除的測試資料）。
功能都在、系統也活著，缺的是「知道怎麼用」——所以這一版把說明做進系統裡，
而不是另外生一份文件給人自己找。

## ① 使用說明（選單 →「📖 使用說明」，所有人皆可用）

- **16 段說明**，分成四個身分層級：所有人（首頁、報名、通知、帳號）、
  一般使用者（我的報名與成績、公告中心）、管理員（賽事、審核候補、隊伍、成績、營運與日誌、帳號管理、回收桶、CSV）、
  超級管理員以上（備份與還原）。
- **依身分過濾在資料層就決定**：`public/js/guide.js` 的 `sectionsFor(role)` 對
  未知／未登入的角色一律比照訪客；一般使用者**根本拿不到**管理員段落的內容，
  而不是畫出來再用 CSS 藏起來。訪客也看得到說明（只給登入者看就失去意義）。
- 可**搜尋關鍵字**（例如「候補」「成績」「推播」），找不到時有明確提示；
  桌機是左側段落清單＋右側內容，手機改成橫向排列不佔滿畫面。
- 內容只寫系統真的有的東西：**現場報到明白寫「尚未有系統功能，請列印名單人工勾選」**，
  不假裝有。

## ② 管理員操作清單：辦一場賽事的 12 步

從「開好賽事」到「收尾檢視」，每一步都寫明**在系統的哪裡做**
（例如「賽事卡片 → 報名管理」「選單 → 📣 公告中心＋📤 推播紀錄」），
包含審核與候補、隊伍編排、印名單、成績草稿與公布、異常處理。

## ④ 順手修掉（都是檢查跑出來才發現的）

| 問題 | 說明 |
|---|---|
| 選單初始化整段拋錯 | 權限對應表少一個逗號，兩行被合成 `['opsStatsBtn', perm.opsStats]['guideBtn', perm.guide]`，`applyMenuVisibility` 讀到 `undefined` 直接 `TypeError`。**語法檢查（`node --check`）看不出來**，是新的瀏覽器檢查登入後才炸出來的。 |
| 變數名打錯不會被擋 | `var(--cm-border, #e2e8f0)` 的 `--cm-border` 專案裡根本沒有，但「有寫 fallback 就不算未定義」的寬容規則**放行了它**——fallback 是淺色值，於是深色模式下說明視窗會出現一條亮線。改用既有的 `--cm-bd-200`，並在 `scripts/class-coverage.py` 新增 **②-b 提示**：把「有 fallback 但 `:root` 沒有定義的變數」列出來（目前 3 個是刻意的、不算失敗；打錯字的會立刻現形）。 |
| 原生對話框會卡死檢查 | `tests/browser/lib/cdp.js` 過去沒有處理 `alert／confirm／prompt`：一旦彈出，整頁卡住、之後每個 `evaluate` 都只會逾時（看起來像「腳本壞了」）。現在一律**記錄到 `browser.dialogs` 並自動以「取消」結束**（取消 ≠ 確認，不會誤觸刪除），檢查腳本可事後斷言。 |
