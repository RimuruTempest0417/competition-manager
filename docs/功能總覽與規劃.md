### 8.7 暫緩或不建議（附理由）

| 項目 | 決定 | 理由 |
|---|---|---|
| 引入前端框架（React / Vue） | 不建議 | 與嚴格 CSP（script-src 'self'）及「純手寫、無外部套件」的既有慣例衝突，目前規模不需要 |
| 用 Supabase Storage 存海報 | 不建議 | anon key 無法建立 bucket（已改為存資料庫、由自家端點供應，效果相同） |
| 對 anon key 開放 RLS policy | 不建議 | 等於把資料庫直接暴露給任何拿到金鑰的人（正解見 P0 的 service_role 升級） |
| 手機原生 App（iOS / Android） | 暫緩 | PWA 已可加入主畫面全螢幕使用；維護兩套程式成本高 |
| 線上繳費 / 金流串接 | 暫緩 | 需要金流帳號與法遵流程，若无實際收費需求不急 |
| 自動化爬蟲接入外部賽事 | 暫緩 | 需先確認目標網站條款與資料格式（見第七節第 6 項） |
