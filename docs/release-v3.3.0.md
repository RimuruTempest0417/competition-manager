# v3.3.0 — 賽事規程 PDF 附件（P1-6）

**一句話**：每場賽事可以放一份規程 PDF；設定好之後，賽事卡片上就多一個「📘 規程」按鈕，
**任何人都能打開**（參賽者、家長、現場工作人員），管理員隨時可以換一份或移除。

## 怎麼用

1. 管理員在賽事卡片按「編輯」→ 表單下方「📘 賽事規程 PDF（選填，公開給所有人看）」。
2. 選 PDF（可順便取個名字，例如「2026 秋季盃競賽規程」）→ 按「**上傳規程**」→ 立刻生效（不必再儲存賽事資料）。
3. 卡片上出現「📘 規程」按鈕；點下去**另開新視窗**由瀏覽器內建的 PDF 檢視器開啟（想存檔就自己另存）。
4. 要換版本：重新選檔上傳即可（一場賽事只會有一份，直接覆蓋）。要拿掉：按「移除規程」。

## 檔案把關（三個地方都驗）

| 關卡 | 規則 | 為什麼 |
|---|---|---|
| 瀏覽器 | 檔案要是 `.pdf` 或 MIME 是 PDF，且 ≤3MB | 先擋掉明顯選錯的檔案，不浪費上傳 |
| 伺服器 | **一定要看檔頭 `%PDF-`** | 只看副檔名或 MIME 會被騙（改個檔名就能傳任何東西） |
| 大小 | 上限 **3MB** | Vercel 函式的請求上限是 4.5MB，而 base64 會膨脹約 4/3；3MB 上傳後約 4MB，仍在安全範圍 |

副檔名寫 `.pdf` 但內容不是 PDF 的檔案，前端會放行（瀏覽器不一定給對的 MIME），**後端一定會擋下來並在畫面說明原因**——而且不會動到原本已上傳的規程。

## 誰能做什麼

- **讀**：不需要登入。規程是公開資訊，訪客與一般使用者都能開（實測訪客讀到的位元組與管理員完全相同）。
- **上傳／移除**：只有管理員以上。未登入 401、一般使用者 403，兩種都會留稽核紀錄（`UPLOAD_DOC`／`DELETE_DOC`）。

## 資料庫

新的 `competition_docs` 表（一場賽事一列，`competition_id` 為主鍵；存法與海報一致：檔案以 base64 存在資料庫，由同源端點供應，所以 **CSP 不用放寬、也不需要外部物件儲存**）。
RLS 已開啟且不加任何 policy → anon key 讀不到，只有伺服器端的 service_role 能存取（與其他資料表相同）。

`migrations/2026-09-26-v3.3.0-docs.sql` — **已由助理套用到你的專案並讀回確認，你不需要自己跑**。

## 效能

賽事列表只多一個小查詢，而且**只撈中介資料**（標籤、大小、上傳時間），不撈檔案內容——列表回應不會因為有人放了 3MB 的規程而變大。專案的效能測試（查詢次數不得隨賽事數量成長）上限由 6 放寬到 7，並在測試裡寫明原因。

## 驗證

- **單元測試 18 項**（`tests/competition-docs.test.js`）：權限（401／403）、非 PDF／假 PDF／空檔／壞 base64 都回 400、超過 3MB 回 413 且不寫入、上傳後訪客讀到的位元組完全相同、`?download=1` 變附件下載且中文檔名用 RFC 5987 編碼、覆蓋不會變成兩份、名稱過長會截短、沒有附件回 404、不存在的賽事回 404、資料表未建時回 503 並指出要跑哪支 migration、每個寫入都留稽核。
- **真 Chrome 介面檢查 32 項**（`tests/browser/doc-check.js`）：沒有附件的賽事不會出現空按鈕；選檔後才出現「上傳規程」；上傳後卡片長出按鈕且資料庫內容與原檔位元組完全相同；**假 PDF 被後端擋下且不覆蓋原有附件**；超過 3MB 在畫面就被擋（沒有送出請求）；按鈕是另開新視窗的連結且指向規程端點；**訪客也看得到、讀得到同一份**，但看不到「編輯」；移除後按鈕消失、端點回 404、稽核留一筆；另一場賽事不受影響；沒有前端例外。全程不寫任何檔案到磁碟（檔案用頁面內建的 File 物件假造，下載在 CDP 與頁面層都被攔住）。
- **正式站煙霧測試 +4 項**：訪客可讀規程端點、有規程時回的就是 PDF（沒有則 404，不是 500）、未登入上傳／移除都被拒。

## 檔案

- `server.js` — `parsePdfDataUrl()`（含 `%PDF-` 檔頭檢查）、三個端點（公開讀取、管理員上傳、管理員移除）、列表帶出 `doc_url`／`doc_label`／`doc_bytes`／`doc_uploaded_at`。
- `public/js/app.js` — 卡片「📘 規程」按鈕（公開）、編輯表單的規程上傳／移除（含選檔後才出現上傳鈕、前端大小與格式把關）。
- `public/index.html` — 表單裡的規程區塊。
- `migrations/2026-09-26-v3.3.0-docs.sql`（新）、`tests/competition-docs.test.js`（新）、`tests/browser/doc-check.js`（新）、`tests/browser/prod-smoke.js`（+4 項）、`tests/perf-query-count.test.js`（上限說明）。

## 已知限制

- 一場賽事**一份**附件、**一個 PDF**（合併多份請先在系統外合併，或之後再加「多附件」）。
- 不做站內 PDF 渲染，交給瀏覽器的 PDF 檢視器（少一份程式、也不會有外掛相容問題）。
- 上限 3MB：更大的檔案需要改用外部物件儲存（不是這一版的事）。
